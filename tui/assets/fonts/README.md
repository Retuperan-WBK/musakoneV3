# Bundled font

`NotoSansMono-Regular.ttf` is the unmodified Noto Sans Mono font from:

https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSansMono/NotoSansMono-Regular.ttf

SHA-256: `d9e2b23d19f8230be7146f409a52b1d23117e635e28f2e2892cf91b7382f325b`.

It is embedded so framebuffer lyrics and the Mac preview use the same font,
without relying on fonts installed on the server. See `OFL.txt` for its SIL Open
Font License. The binary exposes that notice with `musakone --font-license`.
